# СПК ЭФФА — официальный сайт

Исходный код публичного сайта **ООО «СПК ЭФФА»**: https://spk-effa.ru/  
Основной репозиторий: https://github.com/kappamaag-crypto/SPKEFFA (ветка `main`).

## Технологии и публикация

Статический сайт: HTML5, CSS3, JavaScript (без сборщика, базы данных, CMS и серверного приложения в этом репозитории). Домен задан в `CNAME`. Публикация предполагает GitHub Pages; фактическую конфигурацию проверьте в Settings → Pages.

Изменения в `main` влияют на публикуемый сайт после выполнения деплоя. Сначала проверяйте изменения в отдельной ветке / pull request.

## Структура

- `index.html` — главная, направления и контакты.
- `blank/` — антикоррозионные материалы Blank и системы АКЗ.
- `ognezaschita/` — огнезащита ЭФФА, системы АКЗ + ОГЗ.
- `veksa/` — промышленные полы VEKSA.
- `kalkulyatory.html` — инженерные расчёты WFT/DFT, расхода, точки росы.
- `raschet.html` — форма заявки на расчёт и КП.
- `docs/` — технические паспорта в PDF (список: [docs/README.md](docs/README.md)).
- `img/`, `css/`, `js/nav.js` — изображения, стили, единая навигация, подвал и согласие на обработку данных.
- `sitemap.xml`, `sitemap-image.xml`, `robots.txt` — SEO и индексация.
- `scripts/check_site.py` — быстрый аудит внутренних ссылок, метаданных, карт сайта и PDF.
- `scripts/verify_tds.py` — выборочная эвристическая сверка ТХ на страницах с паспортами.

## Локальная проверка

Из корня репозитория:

```bash
python3 scripts/check_site.py
python3 scripts/verify_tds.py            # требует pip install pdfplumber
python3 scripts/verify_tds.py --only blank/universal.html
```

В GitHub Actions запускается лёгкая стандартная проверка, без OCR и тяжёлых зависимостей. Тест TDS не заменяет экспертную проверку паспорта и сертификата, особенно для сканированных PDF.

## Добавление товара

1. Создайте карточку в соответствующем каталоге, по образцу существующей.
2. Разместите изображение в `img/products/`, паспорт в `docs/<brand>/`.
3. Сошлитесь на карточку из страницы категории и при необходимости главной.
4. Укажите уникальные `title`, `description`, `h1`, canonical на `https://spk-effa.ru/…`, OG-метаданные и alt изображения.
5. Добавьте URL карточки в `sitemap.xml`, а изображения — в `sitemap-image.xml`.
6. Включите соответствие карточки паспорту в `PAGE_TO_TDS` файла `scripts/verify_tds.py`.
7. Запустите `python3 scripts/check_site.py` и проверьте страницу на мобильном устройстве.

## Формы и персональные данные

Заявки с главной страницы и `raschet.html` принимаются опубликованными Яндекс Формами. Сайт не содержит обработчика Formspree. Перед изменением полей, получателей или сроков хранения заявок проверьте настройки и документы в аккаунте Яндекс Форм, а также актуальность `privacy.html` и внутренних документов Оператора.

## Известные ограничения

Сайт не имеет собственной CMS, backend и серверного сборщика. Изменение карточек и SEO требует изменения исходников. Коммерческие цены не публикуются: КП рассчитывается по запросу. Полноценное браузерное, сетевое, нагрузочное тестирование и проверка доставляемости заявок выполняются отдельно от статического CI.
