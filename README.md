
## Как разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например `kolorido` или `username.github.io`).
2. Загрузите все файлы из этой папки в репозиторий.
3. Зайдите в **Settings → Pages**.
4. Source: **Deploy from a branch** → ветка `main` → папка `/ (root)`.
5. Сохраните. Через 1–2 минуты сайт будет доступен по адресу:
   - `https://username.github.io` (если репозиторий `username.github.io`)
   - или `https://username.github.io/имя-репозитория`

### Быстрая загрузка через командную строку

```bash
cd kolorido-site
git init
git add .
git commit -m "Первый коммит — сайт Колоридо"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

## Добавление новых продуктов

1. Скопируйте любой файл из папки `products/`
2. Измените название, заголовки и текст
3. Добавьте карточку на главной странице (`index.html` → секция `#products`)
