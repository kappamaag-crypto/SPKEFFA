Калькуляторы расчёта ЛКМ

Толщина плёнки, сухой остаток, расход, точка росы — ориентировочные инженерные расчёты

Результаты носят справочный характер. Для коммерческого расчёта по объекту оставьте заявку.

Толщина мокрой плёнки (WFT)

WFT = DFT ÷ (сухой остаток по объёму / 100)

—

Толщина сухой плёнки (DFT)

DFT = WFT × (сухой остаток по объёму / 100)

—

Сухой остаток по объёму

VS% = (DFT / WFT) × 100

—

Теоретическая кроющая способность

м²/л = (VS% / 100) × 1000 / DFT

—

Расход с учётом потерь

Практический расход = теоретический × 100 / (100 − потери%)

—

Ориентир потерь: безвоздушное 20–30%, пневматическое ~40%. Уточняйте по условиям объекта.

Точка росы (приближённо)

Ориентир по температуре воздуха и относительной влажности. Не заменяет психрометр на объекте.

—

Температура поверхности должна быть выше точки росы минимум на 3 °C.
