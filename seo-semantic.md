## Рекомендации по внедрению

1. Title — до 60–70 символов, главный ключ в начале.
2. Description — 140–160 символов, ключи + УТП + призыв.
3. H1 — один на страницу, совпадает с главным интентом.
4. В тексте страницы используйте LSI и дополнительные ключи из keywords.md естественно.
5. После изменений отправьте страницы на переобход в Яндекс.Вебмастере и Google Search Console.
